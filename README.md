# SlideAInel MVP

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере (Chrome, Edge, Safari).
3. Для экспорта PPTX требуется подключение к интернету, чтобы загрузить PptxGenJS с CDN.

## Что уже работает
- Создание редактируемой структуры слайдов по теме (локальная демонстрационная генерация).
- Четыре визуальных стиля: журнальный, научный, тёмный premium, креативный.
- Редактирование заголовка, верхней подписи и основного текста.
- Добавление/удаление слайдов.
- Добавление изображений на отдельные слайды.
- Экспорт презентации в PPTX.
- Автосохранение проекта в localStorage браузера.

## Ограничения MVP
Это первый frontend-прототип, а не подключённая облачная ИИ-система. Загруженные PDF/DOCX/PPTX пока не анализируются: выбор файлов демонстрирует интерфейс вложений. Настоящая генерация текста и извлечение содержимого требуют backend, безопасного хранения файлов и серверного подключения ИИ API. Не вставляйте секретные API-ключи в HTML или браузер.
